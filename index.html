会社概要

2026年2月創業。代表が副業として運営している、アーリーステージの事業です。

200台以上の実機Android端末でアプリのテストと不具合修正を行っています。PythonとADBで、端末の初期設定、機種をまたいだアカウント認証、バッテリーや稼働時間の監視を自動化、AI活用型のテスト自動化基盤を作っています。開発と保守にはClaude Codeを使っていて、今後はClaude APIで画面の読み取り、エラーの切り分け、数百台分のテストレポート作成を自動化する予定です。

About mikuremu

Founded in February 2026. mikuremu is an early-stage, founder-led venture currently operated alongside the founder's primary job.

We test and fix bugs in mobile apps on a fleet of 200+ physical Android devices. We are building an AI-native test automation platform with Python and ADB that automates device setup, cross-device account authentication, and battery and uptime monitoring. We use Claude Code to develop and maintain it, and plan to use the Claude API to automate screen understanding, error triage, and test reporting across hundreds of devices.
